这个博客的文章，都是在一套很轻的工具链里写成的。它不追求"写作软件"的仪式感，只求从有想法到发版之间，路径尽可能短。

## 想法随手记

灵感不是上班时间准时来的。我习惯用手机备忘录随手记一两句，攒成零散的选题池，而不是让灵感稍纵即逝。

记录的标准很低：一句话，能让你之后想起来"当时想写什么"就行。

## 正文用 Markdown

回到电脑前，把提纲变成 Markdown 文件。只用一个编辑器，用最朴素的语法：

- `##` 分小节，每节一个中心
- 引号块和粗体偶尔点缀
- 代码块留给确实要展示的代码

`##` 结构很重要：它逼我先想清楚这篇文章能拆成几个能独立成立的小节，比直接甩一段流水账清晰得多。

## 发版就是一条命令

这个博客的流程是：写好的 `.md` 文件放进 `src/content/posts/`，运行时 `npm run build` 验证没有报错，然后 `git push` 自动部署。

习惯了之后，发一篇文章的摩擦被压到极小，这大概是我能坚持更新的最大原因。

## 小结

> 工具越多，写作的入口就越窄；越容易开始，就越愿意写。

轻量不是简陋，是让"开始"变得毫不费力。写作真正难的从来不是工具，是打开编辑器、写下第一句而已。
