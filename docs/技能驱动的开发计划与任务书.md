### 1.4 ⚠️ 安装位置的脆弱性（重要）

DSH 的技能发现根由**会话工作目录**决定，而非 git 仓库：

```js
// dsh-skill-filesystem：从 cwd 向上找 .git；找不到就返回 cwd 本身
async function findProjectRoot(cwd, fs) {
  let current = cwd;
  while (true) {
    if (pathExists(join(current, ".git"))) return current;
    const parent = dirname(current);
    if (parent === current) return cwd;   // ← 返回原始 cwd
    current = parent;
  }
}
```

**实测验证**（同一次会话内放两个探针技能）：

| 探针位置 | 结果 |
| --- | --- |
| `D:\Code\Deepseek\.dsh\skills\zz-probe-workspace` | ✅ **解析成功** |
| `D:\Code\Deepseek\blog\.dsh\skills\zz-probe-repo` | ❌ 未发现 |

即：**发现根 = 会话 cwd，不是 `blog\.git`**。当前 `D:\Code\Deepseek` 没有 `.git`，所以
`findProjectRoot` 返回 cwd 本身，12 个技能因此可见。

**风险**：若将来在不含 `.git` 的其它目录（或直接在 `blog\` 下）开会话，这 12 个技能**将全部不可见**。
且 `D:\Code\Deepseek\.agents\` **不在任何 git 仓库内** → 技能不受版本控制。

#### 🔴 高 A1：正文在「JS 加载失败」时永久不可见 🟠S

**这是一处会真实发生在用户身上的空白页。**

链路：`BaseLayout.astro:96-101` 用**同步内联**脚本给 `<html>` 加 `.js` 类，
而 `effects.css:5` 据此把正文隐藏：

```css
.js .reveal { opacity: 0; transform: translateY(16px); }   /* effects.css:5 */
```

把内容重新显示出来，**依赖模块脚本** `src/scripts/reveal.ts`（加 `.is-visible`）。
即：**能跑内联脚本、但模块脚本丢失**时（弱网、企业网/运营商劫持、CSP、扩展拦截），

```
无 JS 阻断：proseOpacity = 1        （正常）
阻断 _astro/*.js：proseOpacity = 0  （← 正文整块空白）
阻断 _astro/*（含 CSS）：proseOpacity = 1  （兜底反而生效）
```

**渐进增强被写反了**：兜底只在 CSS 也一起丢失时才生效 —— 而那是最不该指望的情形。
全站 `.reveal` 元素共 **14 处**（首页）/ 5 处（文章页），含 `.prose` 正文容器。

> 源码复核确认：全站**无** `remove('js')`、**无** `<noscript>` 可见性兜底（`noscript` 计数 = 0）。


## 第六部分：验证与发布约定

### 6.1 每个任务的完成定义（DoD）

```powershell
cd D:\Code\Deepseek\blog
npm.cmd run typecheck      # 必须 0 错误
npm.cmd run build          # 必须 49 页成功、sitemap 生成
npm.cmd run preview -- --port 4321
npm.cmd run check          # 必须全绿、exit 0
```

**除上述四项外，凡涉及视觉可测量的改动（T-06/T-14/T-16/T-19）必须额外给出前后实测数值** ——
不接受"看起来没变"。

> ⚠️ `check` 必须对 **preview**（吃 `dist/`）运行，不能对 `dev` 运行 ——
> sitemap 只在构建期产出，对 dev 跑会误报失败。

### 6.2 硬性红线

| 红线 | 原因 |
| --- | --- |
| **改底色/强调色必须复算对比度** | 强调色 `#b44126` 是在暖纸 `#f2ede1` 上算出的 5.03:1；换底后沿用旧值会掉到 AA 以下 |
| **不要动搜索框的开合动画** | 动画与底色是两件事，只钉底色（详见 §5.0） |
| **页头保持不透明** | 不要写 `backdrop-filter`：构建器会丢弃标准属性只留 `-webkit-` 前缀，导致半透明且无模糊 |
| **题头与正文共用同一容器** | 两个各自 `margin: 0 auto` 的盒子必然错位（实测 192px） |

### 6.3 回滚

所有改动走 git 提交 + GitHub Actions 双 workflow（`ci.yml` / `deploy.yml`）。
回滚 = `git revert <sha>` 后推送，GitHub Pages 自动重部署。
