## A1 🔴 JS 加载失败时正文永久空白

- **问题**：`effects.css:5` 的 `.js .reveal { opacity: 0 }` + `BaseLayout` 内联脚本加 `.js` 类 + `reveal.ts` 加 `.is-visible`，若模块脚本丢失则正文永久透明。
- **排查**：`git log` 发现提交 **d5794a6** `fix(T-12): JS 加载失败时正文不再永久空白`；`git log -S "revealReady"` 只命中该提交；HEAD `bd7bc49` 当前工作树中 BaseLayout.astro 与 reveal.ts 的实现已含兜底。**交接文档此处标注已过期。**
- **实现现状**：
  - `src/layouts/BaseLayout.astro` 内联 `<script>`：先 `root.classList.add('js')`，再在 `DOMContentLoaded` 时执行 `if (!root.dataset.revealReady) root.classList.remove('js')`。DOMContentLoaded 必定晚于模块脚本的求值或失败，判据确定，不用超时猜。
  - `src/scripts/reveal.ts:9` 在**模块求值处**（非 `onPageLoad` 内）写 `document.documentElement.dataset.revealReady = 'true'`。
- **验收（自建装置实测）**：正常服务但对 `*.js` 返 404 → 实验组 `opacity=1`、`class=""`、`revealReady=null`（兜底生效）；控制组 `opacity=1`、`class="js"`、`revealReady="true"`。
- **结果**：✅ 无需改码；已把实测转为回归断言（见 P0-3 ⑤）。
- **收尾**：临时服务脚本已删除，端口已释放。
